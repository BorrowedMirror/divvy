# Translations

Divvy's UI is translated with [i18next](https://www.i18next.com/) and is laid out for
[Crowdin](https://crowdin.com/).

| Item | Location |
| --- | --- |
| Source strings (English) | `web/src/i18n/locales/en/translation.json` |
| Translations | `web/src/i18n/locales/<locale>/translation.json` |
| Supported languages + endonyms | `web/src/i18n/languages.ts` |
| Crowdin config | `.crowdin.yml` |
| Sync workflow | `.github/workflows/crowdin.yml` (uploads sources on change, opens a PR with downloads weekly) |
| Tray menu strings | `tray.*` keys, read by `internal/app/trayi18n.go` from the same JSON files (embedded by the `web` Go package) |

## Supported languages

English, German, French, Spanish, Portuguese (Brazil), Italian, Polish, Russian, Ukrainian,
Turkish, Japanese, Korean, Simplified Chinese, Traditional Chinese and Thai. These are the
languages most Path of Exile players use.

## Rules (enforced by `web/src/i18n/i18n.test.ts`)

- Every non-English file must translate every key (no empty strings) and may not add keys.
- `{{placeholders}}` must be kept exactly.
- Plurals use i18next's CLDR suffixes; each language must provide exactly the plural
  categories `Intl.PluralRules` reports for it (e.g. `ru`: `_one _few _many _other`, `ja`: `_other`).
- Game terms (Divine Orb, Exalted Orb, Waystone, League, item class names) follow the official
  in-game translation for that language where one exists; otherwise keep the English term.

## Adding a language

1. Add `{ code, name }` to `web/src/i18n/languages.ts` (code = Crowdin locale / directory name).
2. Add a `languages_mapping` entry in `.crowdin.yml` if Crowdin's code differs.
3. Create `web/src/i18n/locales/<code>/translation.json` (or let Crowdin create it).
4. Add the code to `TrayLocales` in `internal/app/trayi18n.go`.

## Game text

This page covers the UI. Item text copied from a non-English game client is a separate matter:
`internal/core/l10n.go` translates it to the English text the parser understands, using tables
built from the game's own data (see [Game translations](../CONTRIBUTING.md#game-translations)).
